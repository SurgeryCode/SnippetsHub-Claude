Frequently Asked Questions

Will this work with my theme?
Yes. The Checkout Order Bump is built as a standard Shopify OS 2.0 section and is compatible with all major themes. Highly customized or legacy themes may need minor CSS adjustments to align the card above the checkout button.

Does it require an app or third-party service?
No. It is 100% native Shopify code — Liquid, CSS, and Vanilla JS. No app subscription, no external service, no monthly fees.

Can I show a discounted price?
Yes. Set a "Compare at price" on the bump product in Shopify Admin. The card automatically shows the original price crossed out and displays a "Save X" indicator.

Does it update the cart counter and cart drawer?
Yes. The JavaScript fires standard Shopify cart events (`cart:refresh`, `cart:updated`) and updates header cart count elements supported by Dawn, Sense, Debut, and other major themes.

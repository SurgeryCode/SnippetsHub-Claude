Frequently Asked Questions

How does the drawer open?
Automatically on click of any element with data-cart-toggle, href="/cart", or via a custom event. Add data-cart-toggle to your theme's cart icon button — that's all it takes.

Do recommendations require setup?
No. They use Shopify's native Product Recommendations API which is active on all Shopify stores by default. Recommendations improve automatically as your store gets more orders.

Can I set the free shipping threshold to match my store's currency?
Yes. The threshold is set in whole currency units (e.g., 200 = 200 PLN / 200 USD). Works with all standard currencies.

Do I need a developer to install this?
No. Upload files, add one Liquid tag to theme.liquid, add a data attribute to your cart icon, then configure in Theme Editor. Expert Install available at checkout.

Frequently Asked Questions

Does this use JavaScript?
No. The section is pure HTML and CSS — the lightest possible implementation. No JavaScript, no library, no performance impact on your product page.

Can I add my own custom icons?
Yes. Each badge block has a "Custom icon" field — enter any emoji, Unicode character, or text. This overrides the preset SVG icon for that badge.

Unlimited — there is no block limit set in the schema. Add as many as your layout requires.

## Persona 1: "The Non-Technical Merchant" — Marek

**Wiek:** 32–45 lat
**Zawód:** Właściciel sklepu Shopify (branża: moda, home decor, suplementy)
**Techniczność:** ⭐☆☆☆☆ — nie programuje, boi się kodu

### Ból
- Chce poprawić konwersję ale nie wie jak implementować kod
- Boi się zepsuć sklep
- Agencje są za drogie, aplikacje Shopify spowalniają sklep

### Czego szuka
- "Copy and paste" — maksymalnie proste
- Instrukcja wideo krok po kroku
- Ktoś kto to za niego zrobi (Expert Install)
- Gwarancja że zadziała z jego motywem

### Jak kupuje
- Czyta opis dokładnie
- Ogląda wideo preview
- Sprawdza czy jest gwarancja zwrotu
- Kupuje Single Site + Expert Install

### Komunikat, który go przekonuje
> "No coding required. Step-by-step video tutorial included. We'll implement it in 24h."

## Persona 2: "The Shopify Agency Developer" — Anna

**Wiek:** 25–35 lat
**Zawód:** Developer w agencji lub freelancer Shopify
**Techniczność:** ⭐⭐⭐⭐⭐ — zna Liquid, JS, CSS

### Ból
- Nie chce pisać od zera tego co ktoś już zrobił dobrze
- Potrzebuje czystego kodu bez śmieciowych bibliotek
- Obsługuje wielu klientów — kupuje licencje multi-site

### Czego szuka
- Kod preview przed zakupem
- Licencja 5 Sites lub Unlimited
- Dokumentacja techniczna
- Vanilla JS, zero dependencies

### Jak kupuje
- Sprawdza Code Preview tab
- Porównuje licencje
- Kupuje Unlimited lub 5 Sites

### Komunikat, który ją przekonuje
> "Clean Vanilla JS. Zero dependencies. Shopify 2.0 compatible. Lifetime updates."

## Persona 3: "The Growing Brand" — Tomasz

**Wiek:** 28–42 lata
**Zawód:** E-commerce manager w rosnącej firmie
**Techniczność:** ⭐⭐☆☆☆ — rozumie technologię ale sam nie koduje

### Ból
- Sklep wygląda jak szablon — potrzebuje wyróżnienia
- App stack jest za duży i spowalnia stronę
- Chce szybkich wyników bez drogich projektów

### Czego szuka
- Konkretne rozwiązania per problem (cart, checkout, hero)
- Developer do jednorazowych zadań
- Potwierdzenie że inne znane marki tego używają

### Jak kupuje
- Przegląda kategorie (Hero, Cart, Checkout)
- Sprawdza "trusted by" i social proof
- Kupuje bundle lub pojedynczy snippet + Developer Hour

### Komunikat, który go przekonuje
> "Professional store look for a fraction of agency prices. Trusted by teams."

# Access & Data Handling (SnippetsHub)

## Policy summary
SnippetsHub **does not collect or store store passwords**. Access to Shopify admin is provided only via **Collaborator access** or a dedicated staff account created by the merchant.

We collect only the minimum data necessary to deliver the service:
- store URL
- contact name
- email
- scope/brief

Data is used **only to perform the requested service**, is **not shared with third parties**, and is **deleted after the job is completed** (unless legal obligations require retention).

## Customer instructions (EN)
1. Go to **Shopify Admin** → **Settings** → **Users and permissions**.
2. Click **Add collaborator**.
3. Enter: {{ contact_email }}
4. Select only the required permissions.
5. Send the invite.

## Customer instructions (PL)
1. Wejdź do **Shopify Admin** → **Ustawienia** → **Użytkownicy i uprawnienia**.
2. Kliknij **Dodaj współpracownika (Collaborator)**.
3. Wpisz: {{ contact_email }}
4. Zaznacz tylko potrzebne uprawnienia.
5. Wyślij zaproszenie.

# SnippetsHub 3D Product Banner (EN)

- Author: SnippetsHub (https://SnippetsHub.com)
- License: © 2025 SnippetsHub & SnippetsHub. Single Shopify store. No redistribution/copying.

## What it does
Section to showcase a 3D model (GLB/GLTF) using `<model-viewer>`, optionally with AR (WebXR / Scene Viewer / Quick Look).

## Installation
1) In the theme editor add the section “SnippetsHub 3D Product Banner”.
2) Configure:
   - `model_url` – URL to `.glb/.gltf`
   - `poster` (optional)
   - `autoplay`, `ar`, background color
3) The section auto-loads `@google/model-viewer` and its JS/CSS assets.

## Files
- sections/surgerycode-3d-product-banner.liquid
- assets/surgerycode-3d-product-banner.css
- assets/surgerycode-3d-product-banner.js

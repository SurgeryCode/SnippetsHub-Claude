## Co robi
Lekki osadzacz YouTube/Vimeo: zamiast ciężkiego iframa wyświetla plakat i ładuje player dopiero po kliknięciu. Poprawia LCP/INP.

## Instalacja
W miejscu użycia:
```liquid
{% render 'surgerycode-lite-video-embed', provider: 'youtube', id: 'VIDEO_ID', title: 'My Video', thumbnail: 'https://img.youtube.com/vi/VIDEO_ID/hqdefault.jpg' %}
```
Dostępne `provider`: `youtube` (domyślnie) lub `vimeo`.

# SnippetsHub Lite Video Embed (EN)

- Author: SnippetsHub (https://SnippetsHub.com)
- License: © 2025 SnippetsHub & SnippetsHub. Single Shopify store. No redistribution/copying.

## What it does
Lightweight YouTube/Vimeo embed: shows a poster and loads the player only on click. Improves LCP/INP.

## Installation
Use where needed:
```liquid
{% render 'surgerycode-lite-video-embed', provider: 'youtube', id: 'VIDEO_ID', title: 'My Video', thumbnail: 'https://img.youtube.com/vi/VIDEO_ID/hqdefault.jpg' %}
```
Available `provider`: `youtube` (default) or `vimeo`.

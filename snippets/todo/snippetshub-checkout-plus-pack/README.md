# SnippetsHub Checkout Plus Pack (EN)

- Author: SnippetsHub (https://SnippetsHub.com)
- License: © 2025 SnippetsHub & SnippetsHub. Single Shopify store. No redistribution/copying.

## What it does
Guidance and patterns for Checkout Extensibility (CE) on Shopify Plus. No theme code is included—the CE logic lives in Admin/App Extensions.

## Scope
- UI Extensions (Banners, Pickup instructions, Consent)
- Branding API (colors, fonts)
- Validation API (field validations)
- Web Pixels (checkout tracking)

## Setup / usage
- Create or install an app with CE extensions (Shopify CLI / partners).
- Configure extensions and assign to a checkout profile.
- See Shopify CE docs: https://shopify.dev/docs/api/checkout-ui-extensions

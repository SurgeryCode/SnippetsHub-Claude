## Standard jakości (checklist przed publikacją)

- [ ] `README.md` z instrukcją instalacji (EN)
- [ ] `manifest.json` z metadanymi
- [ ] `LICENSE.md`
- [ ] Liquid section z pełnym `{% schema %}`
- [ ] CSS w osobnym pliku assets (prefiks `snh-`)
- [ ] JS Vanilla, zero dependencies (prefiks `snh-`)
- [ ] ARIA attributes (role, aria-label)
- [ ] Przetestowane na Dawn + Shopify OS 2.0
- [ ] Opis produktu (Szablon A) w `../snippets-list-ready/{nazwa}/snippet_description/`

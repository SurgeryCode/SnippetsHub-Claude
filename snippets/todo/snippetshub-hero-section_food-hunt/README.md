## Co robi
Responsywna sekcja hero dla branży food/restaurant z interaktywną orbitą dań. Centralne danie zmienia się po kliknięciu miniaturki na orbicie lub strzałek nawigacji. Płynna animacja fade-in. W pełni konfigurowalna przez Theme Editor (kolory, teksty, dania).

## Instalacja
1. Skopiuj `sections/surgerycode-hero-food-hunt.liquid` do katalogu `sections/` motywu.
2. Skopiuj `assets/surgerycode-hero-food-hunt.css` i `assets/surgerycode-hero-food-hunt.js` do `assets/`.
3. W Shopify Theme Editor → **Add section** → „Hero Food Hunt".
4. Dodaj bloki **Dish** (do 6): zdjęcie, nazwa, krótki opis.
5. Ustaw kolory, teksty i przyciski CTA.

## Ustawienia Theme Editor
| Ustawienie | Opis |
|---|---|
| Eyebrow text | Mały tekst nad nagłówkiem |
| Heading accent | Pierwsza linia H1 (kolor akcentu) |
| Heading main | Druga linia H1 |
| Description | Krótki opis |
| Primary Button | Label + URL |
| Secondary Button | Label + URL |
| Primary color | Kolor łuku tła, przycisków, obwódki orbit |
| Background color | Tło sekcji |
| Text color | Kolor treści |
| Accent color | Kolor pierwszej linii nagłówka |

## Bloki Dish (max 6)
| Pole | Opis |
|---|---|
| Image | Zdjęcie dania (zalecane: 420×420px) |
| Dish name | Nazwa wyświetlana pod głównym zdjęciem |
| Short description | Opis wyświetlany pod nazwą |

Pierwsze danie = wyświetlane centralnie na start. Pozostałe (2–6) trafiają na orbitę.

- `assets/surgerycode-hero-food-hunt.css`

# SnippetsHub Hero Food Hunt (EN)

## What it does
Responsive hero section for food/restaurant brands. Central featured dish with an interactive orbit of mini dishes. Click any orbit item or the navigation arrows to switch the featured dish with a smooth fade animation. Fully configurable via Theme Editor.

## Installation
1. Copy `sections/surgerycode-hero-food-hunt.liquid` to your theme's `sections/` folder.
2. Copy both asset files to `assets/`.
3. In the Theme Editor → **Add section** → "Hero Food Hunt".
4. Add **Dish** blocks (up to 6): image, name, short description.
5. Customize colors, text, and CTA buttons.

- `assets/surgerycode-hero-food-hunt.css`

# SnippetsHub Landing Page Creator (EN)

- Author: SnippetsHub (https://SnippetsHub.com)
- License: © 2025 SnippetsHub & SnippetsHub. Single Shopify store. No redistribution/copying.

## What it does
Landing page builder powered by section blocks: hero, text, image, cta, faq. Provides base styles and a small JS placeholder for future interactions.

## Installation
1) In the theme editor add the section “SnippetsHub Landing Page Creator”.
2) Build the page using blocks in the editor (hero/text/image/cta/faq).
3) Assets (CSS/JS) are auto-included by the section.

## Optional templates
- The v1 variant ships with `templates/page.landing.json` (see `snippetshub-landing-page-creator-v1/templates/`). Copy it into your theme’s `templates/` folder to create a ready “landing” page.

## Files
- sections/surgerycode-landing-page-creator.liquid
- assets/surgerycode-landing-page-creator.css
- assets/surgerycode-landing-page-creator.js

# SnippetsHub Sticky Add to Cart Bar

## What this snippet is

Sticky Add to Cart for Product Page is a lightweight Shopify OS 2.0 section that keeps a compact purchase bar visible after shoppers scroll past the main buy area on a product page. It helps merchants keep product context and a clear CTA in view without installing a heavy app.

Use it on Shopify product templates when you want to improve access to the add-to-cart action on mobile and desktop while preserving the theme's native product form flow.

## Features

- Shows a sticky purchase bar only after the main buy area leaves the viewport
- Supports active variant state, price, compare-at price, title, variant title, and optional product image
- Adds the currently selected variant to cart from the sticky CTA
- Includes schema controls for CTA label, visibility, position, and core colors
- Works without external libraries and keeps all selectors scoped under `.SnippetsHub`

## Installation

1. Copy the `assets/`, `sections/`, and `snippets/` files into your Shopify theme.
2. Open the product template in the Theme Editor.
3. Add the `SNH Sticky Add to Cart` section.
4. Configure visibility, colors, position, and content options in the section schema.
5. Test variant switching, add to cart, and mobile responsiveness on your theme.

## Notes

- The section is designed for standard Shopify product forms that submit to `/cart/add`.
- Bundle builders and advanced custom product flows are outside the current MVP scope.
- If a theme dispatches its own cart drawer events, you may optionally extend the JS event hooks already included in the asset.

When shoppers scroll down a product page, the main add-to-cart button often disappears from view. That creates friction, especially on mobile, and can reduce add-to-cart rate.

This snippet keeps a clean, compact purchase bar visible once the main buy area leaves the viewport, so shoppers can add the active variant to cart faster and with less friction.

#### Key features

- Sticky CTA appears after the main product form is out of view
- Supports current variant title, price, compare-at price, and optional image
- Adds the selected variant to cart from the sticky bar
- Merchant-controlled schema settings for CTA label, colors, position, and device visibility
- Lightweight vanilla Liquid, CSS, and JavaScript implementation

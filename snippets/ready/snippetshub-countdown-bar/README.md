# SnippetsHub Countdown Bar

## What this snippet is

SnippetsHub Countdown Bar is a Shopify OS 2.0 announcement-style section that helps merchants run seasonal promotions with a visible timer, CTA buttons, and theme presets for key ecommerce events.

Use it when you want a product-ready promo bar for campaigns such as Black Friday, Cyber Monday, Valentine's Day, Easter, or evergreen countdown offers without installing an app.

## Features

- Seasonal countdown bar with multiple campaign-ready visual themes
- CTA button support with primary and secondary actions
- Countdown timer with editable labels for days, hours, minutes, and seconds
- Scroll text / marquee option for promo messaging
- Close button and responsive layout controls
- Fully theme-editor configurable Shopify section

## Installation

1. Copy the section and asset files into your Shopify theme.
2. Open the Theme Editor and add the `SnippetsHub Countdown Bar` section.
3. Configure the campaign theme, CTA labels, links, timing, and colors.
4. Test desktop and mobile layouts before publishing.
